Un candidato envía su CV por mail → el sistema lo registra en Airtable → Claude evalúa el fit contra el puesto y asigna score/categoría → si es Alta prioridad, se notifica a RRHH por Slack y el sistema espera aprobación humana (HITL) → una vez aprobado, se envía un mail automático de respuesta al candidato. Los datos incompletos y las fallas de API quedan registrados como excepción controlada, sin interrumpir el sistema.
